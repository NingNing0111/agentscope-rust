控制台（Console）模块的目标是提供开箱即用的终端交互界面：无需启动 web 服务或手写事件分发逻辑，就能在命令行里与智能体对话，并实时看到回复、思考过程与工具调用的完整事件流。它主要用于开发阶段的快速调试与行为验证。

## Rust 侧现状

AgentScope Rust 目前尚未提供库级控制台模块：

- 尚无内置的交互式聊天命令或事件渲染器。
- 仓库内置示例 `examples/chat` 已覆盖「流式对话 + 逐类型事件分发」的核心能力，可作为自行构建终端交互的起点。

## 缺失范围

| 能力 | Rust 现状 |
|------|-----------|
| 库级控制台模块（交互式聊天 + 事件渲染） | 未实现 |
| 内置终端交互入口 | 无仓库内置命令；需基于事件流自行构建 |

## 替代能力

如需在终端与智能体交互，可基于以下能力自行组装：

- **`AgentEvent` 事件流**：`reply_stream` 产出 33 种事件（文本 / 思考 / 工具调用 / 结果等），按需渲染即可复现完整对话过程（见 [消息与事件](message-and-event)）。
- **`examples/chat` 示例**：已演示逐类型消费事件流的完整写法，可直接参照或改造。

这样既能获得终端交互的调试体验，又无需等待库级控制台模块落地。
