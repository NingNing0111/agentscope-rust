# 技能 Hub（计划中）

## 能力概述

技能 Hub 是技能的注册与分发中心：开发者浏览一个技能目录，找到想要的 Markdown 技能包（见 [tool/skill](../../building-blocks/tool/skill) 对技能的解释），一键安装到用户库，之后智能体即可加载使用。它解决的是**技能复用与分享**问题——写好的技能可以公开供他人安装。

## Rust 缺失范围

Rust 当前无 hub 服务代码。
