# 分享与发布（计划中）

## 能力概述

分享与发布能力解决「做好的智能体如何交给别人用」的问题：把一个配置好的智能体或工作空间打包、导出，让其他人也能导入运行，或发布到公共渠道供更多人使用。它分为两类：

- **分享**：把智能体 / 工作空间交给特定的人或团队；
- **发布**：公开分发，让任意使用者可以拉取运行。

典型场景：团队内共享一个调好的智能体配置，或把某个技能 / 工具组合发布成可复用的公共能力。
