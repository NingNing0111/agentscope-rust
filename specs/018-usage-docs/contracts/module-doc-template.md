# Contract: 模块文档结构模板

**Version**: 1.0.0 | **Date**: 2026-08-01 | **Feature**: specs/018-usage-docs

每篇模块文档（`docs/{zh,en}/modules/*.md`）MUST 遵循以下 7 章节结构。章节标题文字可按语种翻译，但数量、顺序、内容职责 MUST 一致（对应契约 B-1）。

## 结构契约

```markdown
# <模块名> / <Module Name>

> 一句话定位：本模块解决什么问题。

## 1. 模块概述 (Overview)

- 模块的职责与适用场景
- 对应 crate 名称（如 `agent_scope_tool`）及在分层中的位置
- 前置阅读（链接到依赖的模块文档）

## 2. 核心概念与主要公开类型 (Core Concepts)

- 核心概念解释（面向使用者的行为语义，非内部实现）
- 主要公开类型/trait 表格：名称 | 职责 | 典型获取方式
- 扩展点（如 `Arc<dyn Tool>` 模式的接入方式）

## 3. 快速示例 (Quick Example)

- 一个端到端可运行的最小示例，覆盖本模块核心使用路径
- 示例 MUST 符合契约 E-1/E-2/E-3（锚定 examples/，标注来源）

## 4. 关键用法模式 (Usage Patterns)

- 2-4 个常见使用场景的模式化说明（如：注册自定义工具、配置超时与取消、流式消费事件）
- 每个模式配简短代码片段 + 行为说明

## 5. 错误与不支持的能力 (Errors & Unsupported)

- 本模块可能返回的错误类型及触发条件（类型化错误，宪法第十三条）
- 返回 `UnsupportedFeature` 的能力清单（与 capability-matrix.json 一致）
- 常见错误排查（FAQ 式，可选）

## 6. 兼容性 (Compatibility)

- 按契约 documentation-layout.md §5 格式填写
- 兼容等级（L1-L4）、已知偏差、不支持的能力

## 7. 相关模块 (See Also)

- 同语种的相关模块文档链接（2-5 个）
```

## 章节-需求追溯

| 章节 | 支撑的需求 |
|------|-----------|
| 1 概述 | FR-005（统一结构） |
| 2 核心概念 | US2 验收场景 1（不读源码理解模块） |
| 3 快速示例 | FR-006、SC-004（可运行示例） |
| 4 用法模式 | US2 验收场景 1/2 |
| 5 错误与不支持 | 宪法第五条/第十三条、US2 验收场景 3 |
| 6 兼容性 | FR-007、SC-005、宪法第十八条 |
| 7 相关模块 | FR-002/SC-002（导航互联） |

## 质量红线

- 任何章节缺失即视为该篇文档未完成（不适用章节允许保留标题并注明"本模块无此类内容"，如纯数据模块无"不支持的能力"）。
- 第 3 章示例必须真实可运行——禁止示意性伪代码（`// ... 省略` 不允许出现在快速示例中，用法模式章节的片段除外但需标注为片段）。
- 第 5/6 章内容 MUST 逐条对照 capability-matrix.json 与代码核实，禁止凭记忆填写。
