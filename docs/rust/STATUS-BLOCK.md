# 状态块规范（Status Block Guide）

**目的**: 定义 `docs/rust/zh/` 每个页面的「Rust 实现状态」标注规范。三个档位为唯一合法取值，禁止其他措辞（宪法 §5 不允许伪兼容）。

## 三档模板

每个页面在 frontmatter 之后、首节之前 MUST 放置一个 `<Note>` 状态块。

### 已实现

```mdx
<Note>
**Rust 实现状态**: 已实现。本文档描述的能力在 AgentScope Rust 中可用。
</Note>
```

### 部分支持

```mdx
<Note>
**Rust 实现状态**: 部分支持。
- 已支持：<列出支持范围>
- 尚未实现：<列出缺失边界>
</Note>
```

### 计划中

```mdx
<Note>
**Rust 实现状态**: 计划中。该能力在 AgentScope Rust 中尚未实现。当前 Rust 侧可用的替代能力见 <链接>（如有）。
</Note>
```

## 使用规则

- 状态块必须与 `docs/rust/mirror-map.md` 的记录一致。
- **已实现**页：可包含真实 Rust 代码示例（引用 `examples/`）。
- **部分支持**页：必须同时列出「已支持 / 尚未实现」两列，不得笼统标注。
- **计划中**页：MUST NOT 出现 Rust 代码块或伪造的 Rust API 用法；仅说明能力简介与 Rust 缺失范围，可链接替代能力页面。
- 禁止措辞：「完全支持」「即将支持」「差不多支持」等模糊表述。
