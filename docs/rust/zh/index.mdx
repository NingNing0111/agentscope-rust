AgentScope Rust（`agent_scope_*` crates）是 **AgentScope 的 Rust 重构版**——一个以 Rust 多 crate workspace 组织的 Agent 开发框架。核心能力位于 `crates/agent_scope_*`，每个 crate 是独立 package，可按需单独依赖。

<Note>
**版本声明**：Rust 实现的兼容基线锁定 **AgentScope Python v2.0.5**（commit `27b6a0d2`）。尚未实现的能力在对应页面标注「计划中」——这是有意的诚实标注，保证每个页面的内容真实可用（见 [`STATUS-BLOCK.md`](../STATUS-BLOCK.md) 与 [`mirror-map.md`](../mirror-map.md)）。
</Note>

- **安全**：依托权限系统（allow/deny/ask）、人机协同确认（Human-in-the-Loop）与本地隔离沙箱，构筑安全防线。
- **高效**：依据工具特性柔性编排，支持工具并发或顺序调度。
- **灵活**：通过 Agent 中间件（Middleware，9 个钩子点）无侵入定制运行时行为。
- **完备**：覆盖 Agent 编排、工具系统、记忆、RAG、工作空间、沙箱与事件驱动流式输出。
